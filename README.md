# 🧪 Автоматика отбора спирта (Старт-Стоп / ШИМ) на Arduino Nano

Универсальный блок автоматического управления соленоидным клапаном отбора для ректификационной колонны.  
*Разработано и отлажено с использованием ИИ (Gemini).*

---

## 📌 Ключевые возможности

* **Адаптивный алгоритм отбора:**
  * Поддержка режимов: `MANUAL` (ручной), `AUTO` (старт-стоп), `PWM_AUTO` (автоматическое снижение отбора при залётах).
  * Коррекция целевой температуры по барометрическому давлению (коэффициент `0.037 °C / мм рт. ст.`).
  * Выдержка 5-минутного режима стабилизации колонны после залёта.
  * Автоматический счётчик залётов температуры.
* **Бесшумное управление клапаном:**
  * Ультразвуковая частота ШИМ **31.25 кГц** на пине `D3` (без писка и гула соленоида).
  * Форсированный двухрежимный импульс: 100% ШИМ при открытии (150 мс) и переход в экономный режим удержания (~35% мощности) для защиты от перегрева катушки.
* **Высокая точность измерений:**
  * **Температура царги:** Прецизионный датчик Pt1000 через аппаратный SPI-драйвер `MAX31865`.
  * **Температура куба:** Датчик `DS18B20` с асинхронным опросом по OneWire.
  * **Атмосферное давление и защита корпуса:** Барометр `BMP180` (I2C) с функцией контроля перегрева блока автоматики.
* **Удобная индикация и интерфейс:**
  * Дисплей LCD1602 (I2C) с 3 переключаемыми экранами (Главный, Уставки/Залёты, Диагностика).
  * Звуковое сопровождение (неблокирующий зуммер).
  * 3 светодиодных индикатора состояния (Залёт/Авария, Режим, Соленоид).

## 🕹️ Управление кнопками

| Кнопка | Пин | Функция |
| :--- | :---: | :--- |
| **Кнопка 1** | `A0` | Вкл / Выкл клапан отбора (в режиме `MANUAL`) |
| **Кнопка 2** | `A1` | Переключение режимов (`MANUAL` $\rightarrow$ `AUTO` $\rightarrow$ `PWM_AUTO`) |
| **Кнопка 3** | `A2` | Фиксация базовой температуры `Tbase`, давления `Pbase` и сброс залётов |
| **Кнопка 4** | `A3` | Корректировка скважности ШИМ (-10%) |
| **Кнопка 5** | `D8` | Переключение страниц дисплея (1 $\rightarrow$ 2 $\rightarrow$ 3) |

🛠️ Особенности сборки и чек-лист
[x] Загрузка прошивки (UART): Пины D0 (RX) и D1 (TX) оставлены абсолютно свободными для надежной прошивки по USB.

[x] Кнопки: Подключаются напрямую между цифровыми/аналоговыми входами и GND. Используется внутренняя подтяжка INPUT_PULLUP.

[x] ШИМ Соленоида: Работает на пине D3 (Timer 2) на частоте 31.25 кГц, что не вызывает аппаратно-таймерных конфликтов с SPI и системным миллисекундным таймером millis().

[x] Отсутствие аппаратных конфликтов: Пин D10 задействован под CS шины SPI, гарантируя стабильность интерфейса MAX31865.
